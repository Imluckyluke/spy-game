# 🕵️ بازی جاسوس (فارسی)

بازی «کلمهٔ پنهان» برای دورهمی‌های ایرانی. یک کلمهٔ فارسی به همه نشان داده می‌شود، جز **جاسوس** که به‌جای کلمه، فقط یک **راهنمای مرتبط** می‌بیند.

## قوانین بازی
1. تعداد بازیکن‌ها (۳ تا ۱۶) و تعداد جاسوس‌ها مشخص می‌شود.
2. گوشی بین بازیکن‌ها می‌چرخد؛ هر نفر روی «نقش من را ببین» می‌زند:
   - **غیرجاسوس:** کلمهٔ اصلی را می‌بیند.
   - **جاسوس:** «تو جاسوسی!» + یک راهنمای مرتبط با کلمه.
3. بعد از خواندن، دکمهٔ «پنهان کن و نفر بعدی» را می‌زند و گوشی را می‌دهد.
4. نقش باید مخفی بماند؛ جاسوس باید وانمود کند کلمه را می‌داند.
5. بعد از گفت‌وگو، «پایان و افشا» کلمهٔ واقعی و شمارهٔ جاسوس‌ها را نشان می‌دهد.

## امکانات
- ۱۰۰ کلمهٔ فارسی، هرکدام با راهنمای اختصاصی
- انتخاب ۳ تا ۱۶ بازیکن و ۱ تا ۳ جاسوس
- تایمر حلقوی برای مرحلهٔ گفت‌وگو (۳۰ تا ۱۲۰ ثانیه)
- بازی تک‌دستی: فقط یک گوشی لازم است
- طراحی راست‌به‌چپ، واکنش‌گرا و مناسب موبایل
- بدون نصب، بدون سرور، بدون حساب کاربری

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید، یا:

```bash
python3 -m http.server 8000
```

## ساختار
| فایل | کار |
| --- | --- |
| `index.html` | ساختار صفحه‌ها |
| `style.css` | ظاهر و انیمیشن‌ها |
| `words.js` | ۱۰۰ کلمه + راهنما |
| `app.js` | منطق بازی، تایمر و نقش‌ها |
