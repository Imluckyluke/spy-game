# 🕵️ بازی جاسوس (فارسی)

بازی «کلمهٔ پنهان» با ۱۰۰ کلمهٔ فارسی. دو حالت دارد:

- 🖐️ **حضوری:** یک گوشی بین بازیکن‌ها می‌چرخد.
- 📱 **آنلاین:** میزبان یک «کد روم» می‌سازد و هرکس با گوشی خودش وارد می‌شود و **نقشش را جداگانه** می‌بیند.

## قوانین بازی
1. همهٔ بازیکن‌ها یک کلمهٔ فارسی می‌بینند، جز **جاسوس** که فقط یک **راهنمای مرتبط** می‌بیند.
2. در بازی حضوری گوشی بین بازیکن‌ها می‌چرخد؛ هر نفر دکمهٔ «نقش من را ببین» را می‌زند و بعد از خواندن، «پنهان کن و نفر بعدی».
3. در بازی آنلاین، میزبان کد روم را می‌سازد و بقیه با گوشی خودشان وارد می‌شوند؛ هرکس نقش خودش را روی صفحهٔ خودش می‌بیند.
4. نقش‌ها بین همهٔ بازیکنان از جمله میزبان قرعه‌کشی می‌شود و در پایان، نقش تک‌تک بازیکنان افشا می‌شود
5. هیچ‌کس نباید نقشش را لو بدهد؛ جاسوس وانمود می‌کند کلمه را می‌داند.
6. میزبان تایمر گفت‌وگو را می‌گذرد و با «پایان و افشا» کلمهٔ واقعی و نام جاسوس‌ها را به همه نشان می‌دهد.

## امکانات
- ۱۰۰ کلمهٔ فارسی نسبتاً غیرمستقیم، هرکدام با یک راهنمای غیرمستقیم (ویژگی، اثر یا ارتباط) — نه مترادف مستقیم
- بازی حضوری: ۳ تا ۱۶ بازیکن با یک گوشی
- بازی آنلاین: تا ۱۲ بازیکن، هرکدام با گوشی خودش + کد روم و اشتراک‌گذاری لینک
- میزبان می‌تواند بازیکن باشد یا فقط داور/میزبان بماند (برای ۳ بازیکن با یک گوشی اضافه)
- تم تیرهٔ تخت و **تک‌رنگ (خاکستری)**، بدون گرادیانت و بدون رنگ تزئینی — فقط رنگ جاسوس (قرمز) و راهنما (کهربایی)
- تایمر حلقوی هماهنگ بین همهٔ گوشی‌ها با ۸ بازهٔ زمانی (۳۰ ثانیه تا ۱۰ دقیقه)
- بعد از پایان تایم، کلمه فقط با فشردن «پایان و افشا» رو می‌آید
- راهنمای جاسوس در کادر بزرگ و جداگانه نمایش داده می‌شود (کلمهٔ اصلی هرگز به جاسوس نشان داده نمی‌شود)
- طراحی راست‌به‌چپ، واکنش‌گرا، بدون نصب و بدون حساب کاربری

## ساختار

| فایل | کار |
| --- | --- |
| `index.html` | ساختار صفحه‌ها |
| `fonts/` | فونت وزیرمتن (خودمیزبان) |
| `vendor/` | کتابخانهٔ mqtt.js (خودمیزبان — بدون هیچ CDN خارجی) |
| `icons/` | آیکون‌های PWA (۱۹۲، ۵۱۲، maskable، iOS) |
| `manifest.webmanifest` | مانیفست نصب روی گوشی |
| `sw.js` | سرویس‌ورکر: کارکرد آفلاین و به‌روزرسانی خودکار |
| `style.css` | فونت، تم تیرهٔ تک‌رنگ و چیدمان |
| `words.js` | ۱۰۰ کلمه + راهنما |
| `app.js` | منطق بازی حضوری |
| `online.js` | ساخت روم، ورود با کد و هماهنگی آنلاین |

## بازی آنلاین چطور کار می‌کند؟
نقش هر بازیکن مستقیم و رمزنگاری‌شده (DTLS/WebSocket) به همان گوشه فرستاده می‌شود و از کس دیگری دیده نمی‌شود.
برای هماهنگی از یک بروکر عمومی رایگان MQTT روی WebSocket استفاده می‌شود؛ اگر در شبکهٔ شما کار نکرد، در «تنظیمات پیشرفته» یک نشانی دلخواه (مثلاً سرور Mosquitto یا EMQX خودتان) بنویسید:

```bash
docker run -it --rm -p 8084:8084 -p 9001:9001 emqx/emqx
# سپس در تنظیمات پیشرفته: wss://your-domain:8084/mqtt
```

> کد روم را مثل رمز بدانید: هرکس کد را داشته باشد می‌تواند به روم بپیوندد. میزبان همیشه باید گوشی‌اش روشن و صفحه باز بماند.

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید، یا:

```bash
python3 -m http.server 8000
```
